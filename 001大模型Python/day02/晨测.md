如何理解小整数池?范围是多少
Python 为了**节省内存、提升效率**，提前缓存了一段范围内的整数对象，程序中只要用到这个区间的整数，
永远复用同一个内存地址，不会重复新建对象，这个缓存区域叫**小整数池**
在[-5,256]之间的数字，如果不是第一次出现，python不会重复创建新的地址保存，
而是让这些重复出现的数字对象指向同一个内存空间
